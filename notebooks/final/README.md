# Pipeline final

`01_final_pipeline.ipynb` é o notebook canônico para reproduzir o treinamento e a avaliação. A implementação reutilizável está em `src/`; os notebooks de pesquisa e versões anteriores ficam em `notebooks/exploratory/`.

Execute o notebook a partir da raiz do repositório. O conjunto de validação é separado do diretório de treino e o conjunto de teste é usado somente depois do treinamento.
